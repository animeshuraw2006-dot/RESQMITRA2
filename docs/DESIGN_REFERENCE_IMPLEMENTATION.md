# ResQMitra SOS UI implementation notes

This update incorporates the supplied visual references for:
- Home dashboard: high-alert confirmation, standard SOS, Siren/Flashlight preview controls and helpline.
- SOS type chooser: General SOS, Women SOS and Child SOS.
- General SOS category grid: medical emergency, accident, fire, flood/water, rescue, evacuation, missing person, shelter, food & water, blood needed, drug abuse and other emergency.
- Women SOS category grid: immediate danger, harassment/threat, unsafe situation, escort assistance, medical emergency, safe shelter, blood needed and other women's emergency.
- Child SOS category grid: lost/missing child, abuse/unsafe touch, stranger danger, bullying, medical emergency, safe pickup/trusted adult, child in danger and other child emergency.

Tapping a category opens the existing SOS request form with that category preselected. The app's SOS service and backend setup are still required for real incident delivery. The siren and flashlight controls on the home screen remain explicitly labelled UI previews; they are not hardware integrations. Always call India's 112 emergency number for immediate danger.
